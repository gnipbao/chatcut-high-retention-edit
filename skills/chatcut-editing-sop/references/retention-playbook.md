# 留存节奏手册

把“网感”拆成可执行、可检查的规则。来源：参考教程（约 12:52 的竖屏口播包装逐帧讲解）、ChatCut 自带 talking-head 指南，以及公开的短视频剪辑研究。数字是起点，不是硬规定，以试看效果为准。

## 1. Hook：前 3 秒

**原则**：首帧就给出“看下去的理由”，第一句话 1 秒内兑现首帧的承诺。不要 logo、寒暄、“今天给大家讲”。

可以从原话里挑的 Hook 类型（必须是原话，不编造）：

| 类型 | 识别特征 | 例 |
| --- | --- | --- |
| 痛点/矛盾 | “想 A 又怕 B”“很多人以为…其实…” | “想变美，又不想改变自己的样子” |
| 结果前置 | 说出改变后的效果 | “调整了眉骨，眼睛也变得有神了” |
| 反常识 | “不是越…越好”“千万别…” | “眉心不是越饱满越好” |
| 直接提问 | 观众会在心里回答的问题 | “你知道显老的真正原因吗” |
| 数字/清单 | “两个部位”“3 个信号” | “决定气质的其实是这两个地方” |

**落地**：
- 冷开场 = 把 Hook 句复制到最前，再接正文开头；正文里原句保留（观众会听到两次，第二次是自然的“回扣”）。若原句太长，只取能独立成立的半句。
- 首帧必须有大字（Hook 关键词花字），0–0.5 秒出现；前 3 秒内再有一次跳推或花字切换。
- Hook 之后 3–8 秒内给出“承诺”：这条视频会讲几个点/得到什么。

## 2. 视觉节拍

- 竖屏口播的视觉变化间隔起点 **2–4 秒**；低于约 1.2 秒显得乱，长于 6 秒就开始流失。按语义点切，不按秒表机械切。
- 推拉（punch-in）放在**句首**或转折词处，交替“推近/拉回”，幅度 110–130%。推拉落点要落在完整句子起点上，不要在句子中间切换。
- 跳切本身是网感的一部分：只要机位、亮度、电平一致，跳切 + 推拉读起来就是“利落”，不必全部用 B-roll 遮。
- 长解释段（>6 秒）三选一：示意图 MG、Slow Push 缓推 + 逐条出现的信息、B-roll/画中画。
- 每 15–20 秒给一次“大变化”（换版式、整屏卡、章节转场），中间用推拉和花字维持小变化。
- 最强的 5 秒内容放在容易流失的位置（约 40%–60% 进度），可以用“下面这个最关键”这种原话做预告。

## 3. 双层花字

- 两段式：上层语境（白，中等字重），下层关键词（金黄，约 1.5 倍，粗黑体）。参考教程里几乎每个重点句都用这一结构。
- 一屏只一个主强调色；同时最多两行花字；花字停留 ≥ 1.2 秒或到该句说完。
- 关键词在**真实起音帧**出现；数字连同单位和限定词（“约”“最多”“因人而异”）一起出现。
- 教程中常见入场：打字光标（短标签）、向右缓入/向左滑动（标题、编号）、模糊发光（提醒注意）、星光闪闪（夸赞/结论）、随机落下（数字）、位置大小关键帧（关键词从后放大到前）。

## 4. 构图与图层技巧（教程提炼）

| 技巧 | 做法 | ChatCut 实现 |
| --- | --- | --- |
| 圆形发光画中画 | 场景图铺底，人物圆形蒙版 + 发光描边 | MG 圆框 + 口播复用层 crop/borderRadius，或 pixel 圆形蒙版 |
| 人物破框 | 人物头部冒出圆框/卡片上沿 | 复制口播层 + AI Portrait Cutout，下半部分用线性蒙版遮住 |
| 文字在人物后 | 大字放在抠像人物层之下、背景之上 | 轨道顺序：背景 → 大字 MG → 抠像口播层 |
| 角落描边人像 | 抠像人物缩小到角落 + 白描边，大画面给信息 | 抠像 + MG 描边 / 磨砂卡 |
| 关键帧位移/缩放 | 标题从屏外滑入、关键词放大后缩小 | MG 内部动画参数 |
| 背景切换转场 | 两张背景图之间的轻转场 | pixel-transition（Cross Dissolve / Luma Blend / Flash） |
| 收尾 | 取消抠像，人物回到居中全景，结论花字 | 恢复原始口播构图 + 结论 MG |

## 5. 结尾

- 结尾句停在信息或情绪的高点，提前半拍收；不加“谢谢观看”。
- 有原话 CTA（“想知道…评论区告诉我”）才做 CTA 包装；没有就做“回环”：结尾画面/花字呼应开头 Hook。
- 最后 0.5–1 秒音乐淡出，不留黑屏尾巴。

## 动画音效对照

参考教程成片在每个动画旁标注了所配音效，归纳为：

| 画面事件 | 音效 | 备注 |
| --- | --- | --- |
| 打字光标 / 逐字出现 | 键盘敲击（短，0.3–0.8 秒） | 只截与字数相当的长度 |
| 向右缓入 / 标题滑入 | Pling / 清脆提示 | |
| 上滑 / 信息卡出现 | 轻 whoosh 或 pop | |
| 模糊发光 / 重点提醒 | 嗖（air whoosh）或 shimmer | |
| 星光闪闪 / 夸赞 | 仙尘 / sparkle | |
| 随机落下 / 数字 | 点击提示 / tick | |
| 位置大小关键帧 / 放大强调 | 叮 / ding | |
| 撞字 / 爆字 | 低频 hit + 短 riser | 全片 ≤3 次 |
| 章节转场 / 背景切换 | 风声 whoosh、扫光 swish | |
| 推拉跳推 | 通常不配；强调句可配极轻 tick | 避免每次推拉都响 |

规则：音效以起音对齐画面事件首帧；同一拍只一个主音效；音效比口播低 8–14 dB 感知响度；连续 3 秒内最多 2 个。
