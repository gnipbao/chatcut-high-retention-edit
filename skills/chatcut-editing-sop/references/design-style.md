# 高网感竖屏口播 · Design Style

教程参考是一条约 12:52 的剪辑教学录屏。取其中竖屏成片的构图和节奏，忽略横屏录屏边框、警示开场、编辑器界面及教程水印。以下色值、字号比例和动效曲线是本 Skill 的设计目标。

## 可移植预设

可把 YAML 作为设计说明使用。保存到 ChatCut Design Style 时按实际界面或工具的字段映射色板、字体和 `styleGuide`。样式用于指导后续包装，具体字幕、卡片、构图和音效由各轮落实。

```yaml
name: 高网感竖屏口播
canvas: {aspect_ratio: '9:16', width: 1080, height: 1920}
palette:
  primary_text: '#FFFFFF'
  keyword_yellow: '#FFD700'
  secondary_mint: '#00F5D4'
  card_base: '#141419'
card:
  background: 'rgba(20, 20, 25, 0.65)'
  backdrop_blur_px: 16
  border: '1.5px solid rgba(255, 255, 255, 0.25)'
typography:
  family: '可用的中文无衬线字体，如思源黑体或同等字体'
  context_weight: 600
  keyword_weight: 800
  context_to_keyword_scale: '1:1.5'
  base_caption_max_chinese_characters_per_line: 12
chapter_card:
  shape: rounded_pill
  position: top_center_safe_area
  duration: chapter
subject:
  centered_a_roll_height_percent: '60–70'
  optional_soft_white_outline_px: 2
b_roll:
  optional_darken_percent: '20–30'
  optional_blur_px: 8
motion:
  enter_ease: 'cubic-bezier(0.22, 1, 0.36, 1)'
```

- 白色负责可读性，黄强调核心数字或关键词，薄荷绿留给少量层级提示。同一屏最多一个主强调色。先实测中文、数字、标点和中英混排的字形。
- 初排可用左侧约 8%、右侧约 15%、顶部约 10%、底部约 18% 的安全区做参考，再按实际平台覆盖层和项目预览校正。标题、脸和口播字幕分别占位。
- 半透明卡的模糊依赖运行环境。需要清晰截图或实际运行不支持背板模糊时，使用同轮廓、较实的深色半透明卡；复杂背景优先局部暗角。带信息的界面和证据画面保持清晰。
- 动效用短促入场、平稳停留。常规字幕避免每词都弹跳。数字只用实际说出的信息，重要单位和限定词留在同一个阅读组。

## 版式轮换

| 版式 | 构图与层级 | 教程取样 |
| --- | --- | --- |
| A · 发光圆形画中画 | 相关实景铺底。章节标题在上，人像圆窗在中上，字幕或关键词在中下。可用背景、人像之间的景深大字，只有在可验证抠像且人物无遮挡时尝试头部微破框。 | 01:45、02:40，新加坡章节。大编号与地名在上，人物居于发光圆窗。 |
| B · 角落人像＋磨砂信息卡 | 人像优先在右下，按平台按钮位置微调。细白描边用于分离背景。上方放章节卡，左侧放随语音逐条出现的简短列表。 | 06:20、07:20，新西兰章节。全幅风景、角落描边人像和中央信息。磨砂卡是本预设的适配。 |
| C · 底部框景＋上方数据 | 人像放在底部有边框的横窗或小窗，留出下方平台区域；上方承载 1–2 组数字和单位。背景保持低干扰。 | 08:00 的加拿大章节使用底部小窗；09:00–11:00 的英国章节用深色底框与上方数据。 |

| D · 抠像破框 / 文字在人物后 | 背景层 → 大号关键词 → 抠像人物层，头部压住大字的一部分形成景深；或人物头顶冒出圆框/卡片上沿。用于全片 1–2 个最强论点。 | 新西兰章节“高度重视”文字从人物身后冒出；新加坡章节人物头部冒出圆形蒙版。 |

### 推拉镜头构图

- 基础机位：人物可见高度约占画面 60%–70%。
- 推近档：1.12–1.20×，头顶留白 ≥ 画面 4%，下巴不压到花字区。
- 特写档：1.25–1.35×，只用于强调句，持续 ≤3 秒后拉回。
- 推拉与示意图/画中画不同时出现；画中画里的人像不加推拉。

教程约 01:30 有打字机入场，04:40 用线性蒙版衔接补镜，10:40 可见关键词大小和颜色切换，11:40 开始按画面事件配音效。参考时间戳用于说明风格，实际剪辑须重取目标素材的时间锚点。
