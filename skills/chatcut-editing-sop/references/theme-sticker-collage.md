# 主题：贴纸抠像风（Sticker Collage）

适合 AI / 产品 / 设计方法论、创作者分享、干货清单、双语及轻知识口播。气质是**轻盈、清爽、高质感手账拼贴**：用淡彩方格纸替换杂乱原背景，主讲人抠像后带一圈**稳定、平滑的粗白贴纸描边**，所有关键词、章节号、清单与参考截图都做成**全息珠光模切贴纸（Die-cut Sticker）**，随口播节奏在人物周围弹出并与人物空间互动。

> 风格来源：对标视频 `新风格/对标剪辑.mp4`（164.6 秒、1920×1080、60fps，整体响度 −14.2 LUFS / LRA 1.8 / TP −3.2 dBTP）逐帧与音轨拆解归纳。只提炼视觉语法、站位、材质、配色与节奏规律，不复制原作的文案、人物或账号信息。

与“明快风”“暗调文案风”的核心差异：

| 维度 | 明快风（默认） | 暗调文案风 | 贴纸抠像风 |
| --- | --- | --- | --- |
| 语速 | 1.10–1.20× 提速 | 1.0×，留白停顿 | 1.0×（或 1.05×），停顿收干净不留长空白 |
| 背景处理 | 保留实景，局部补镜 | 真实环境压暗低调光，纯黑只给插入镜 | **全片人像抠像 + 粗白描边**，淡彩方格纸按章节换底 |
| 画面变化 | 2–4 秒一次（跳推/花字/版式） | 3–4.5 秒一次（机位/黑场/聚光） | **1.5–3.5 秒一次贴纸微节拍** + 人物居中↔左偏平移 + 章节换底 |
| 推拉镜头 | 跳推、快推为主 | 几乎不用（最多缓推） | **不用跳推/快推**；仅用 12–18 帧平滑左右位移让出右侧贴纸板 |
| 文字与字幕 | 底部单行字幕 + 金黄双层花字 | 上方暖白字幕 + 宋体/手写红金 | **默认无底部滚动字幕**，用高频模切贴纸承载骨架信息 |
| 转场 | 扫光、闪白 | 硬切、Dip to Black、圆形聚光 | 贴纸弹性 Pop-in / 淡出；底色 8–12 帧柔和渐变切底 |
| 声音 | 全程 BGM + 每动画配音效 | 深闪避低频氛围乐 + ≤6 音效 | **默认无 BGM**（或极轻 Lo-fi），声音极度克制，全片约 8–15 个轻音效 |
| QA | `--profile bright` | `--profile cinematic` | `--profile sticker` |

## 1. 画幅与构图

- **16:9 横屏（默认对标规格：1920×1080，30fps 或 60fps）**，适合 YouTube、B站、X（Twitter）及桌面教程口播；两种核心站位靠平滑缓动切换，不用硬切跳机位：
  1. **居中对话位（Center Stage）**：人物水平居中靠底（高度占画面约 78–85%，头顶留 15–20% 放彩虹主标题贴纸）。左右两侧留出对称空白区，用来放概念词、手写副标、对比标签、Emoji、红色印章，或穿过头后的弧形连线（如 `input —— output`）。
  2. **左偏演示位（Left-Split Showcase）**：列清单、展示参考截图/界面/提示词卡、或结尾复盘要点时，人物平滑左移至左侧约 1/3（中心 `x ≈ 0.25–0.28`），右侧约 55–60% 成为**贴纸展示板**，逐条弹出编号列表、提问胶囊、倾斜截图卡或带勾选框的行动清单。
- **9:16 竖屏适配（1080×1920，抖音 / 小红书 / 视频号）**：
  - 人物始终居中偏下（高度占画面约 48–55%，肩部贴底），上方 35–42% 作为贴纸主展示板（主标题、大号章节数字、逐条清单、倾斜截图卡），人物左右耳侧放简短手写注释或 Emoji 徽章。
  - 左上常驻章节胶囊移至顶部安全区（`y ≈ 110–160px`），避免撞平台顶部 UI。
- **Z 轴三层互动（景深感来源）**：
  - 底层：淡彩方格纸背景（含细网格与微纸张颗粒）。
  - 中层（人物身后）：超大彩虹主标题、章节大编号、跨头顶弧形连接线（人物头顶与白边轻微压住文字下沿或连线中段，形成自然前后遮挡）。
  - 顶层（人物同层/前景）：带稳定粗白描边的抠像人物，以及少量前景贴纸（如胸前 `+` 符号、右/左侧浮层截图卡）。

## 2. 背景方格纸系统（按章节换底）

全片用柔和的**淡彩网格纸**替代实拍背景：方格线间距约 40–48px（1080p），线条为 1px 极低透明度深灰/浅白线（opacity `0.05–0.08`），叠轻微纸张噪点。每次章节切换或进入总结/高潮时，用 **8–12 帧柔和颜色淡变**换底色：

| 场景 / 章节角色 | 背景主色 | 质感与用法 |
| --- | --- | --- |
| 暖米纸（默认 / 开场 / 总览 / 第 3 章） | `#E5E3D9` | 温暖干净，不抢肤色，整片使用占比最高 |
| 浅薰衣草紫（第 1 章 / 第 4 章 / 概念拆解） | `#DDDAEA` | 理性清爽，和钴蓝文字形成同色系高级呼应 |
| 奶油粉灰（第 2 章 / 案例演示 / 行动清单） | `#E7DFDB` | 柔和亲切，适合承接蓝色系截图或复盘清单 |
| 高饱和钴蓝强调幕（高潮金句，全片 ≤ 1 次） | `#2932C2` | 3–6 秒，叠浅蓝细网格与轻微噪点；配彩虹白边大字与白色背后连线，制造全片最强视觉记忆点 |
| 全息彩虹柔焦幕（终极公式 / 片尾，全片 ≤ 1 次） | `#E0D0F8 → #F8D0E4 → #F4DAC2 → #C2F4CB` | 极低饱和柔和斜向多色渐变 + 方格线，收束全片，明亮有余韵 |

> 换底原则：相邻两章不连用同一底色；高饱和钴蓝幕和彩虹柔焦幕属于“情绪王牌”，各只用 1 次，不要泛滥。

## 3. 人物抠像与粗白描边（标志性视觉锚点）

这是本风格最核心的辨识度，质量不过关会立刻显得廉价：

1. **人像抠像**：在 ChatCut Desktop 里优先对口播片段使用原生人像遮罩（`mask: { nodes: [{ kind: "portrait" }] }`；旧版 Desktop 按 `browse_library` 结果使用 `builtin:effect-ai-portrait-matte` 或 `builtin:effect-mask`）。
2. **稳定、平滑的粗白描边**：
   - 在抠像 Alpha 外围生成一圈**纯白 `#FFFFFF`、宽度约 20–26px（1080p）**的圆滑外扩描边，外缘带极轻微的柔和投影（`rgba(30, 35, 90, 0.08)`，模糊 12–18px），让人物像厚纸模切贴纸一样“浮”在方格纸上。
   - **防闪烁铁律（关键）**：直接对逐帧 AI 抠像 Alpha 做硬膨胀会产生边缘锯齿与高频闪烁。实现自定义 Pixel Effect（走 `chatcut-create-pixel-processor` / `pixel-processing-gen`）时，必须先对 Alpha 做**平滑滤波/轻度高斯模糊再做平滑阈值（smoothstep）外扩**，条件允许时叠加轻度时间域平滑，并检查头发边缘与肩部轮廓在连续说话 3–5 秒内是否稳定不闪。
3. **人物色彩与站位动画**：
   - 肤色保持自然干净，不做暗调重压暗，也不加厚重暗角；仅在原片偏暗/偏灰时轻提曝光（`exposure +0.05 ~ +0.15`）并微调白平衡，使人像融入明亮方格纸。
   - “居中 ↔ 左偏”位移用 **12–18 帧平滑缓动**（`cubic-bezier(0.22, 1, 0.36, 1)`），人物缩放比例保持恒定（不放大特写，不跳推）。

## 4. 字体、配色与贴纸层级

所有叠加信息统一遵守**模切贴纸材质**：纯白或**淡彩全息珠光白边**（白底轮廓边缘带极淡粉/天蓝/薄荷彩虹晕染 + 微细闪粉颗粒）+ 柔和投影（`0 6px 16px rgba(30, 35, 90, 0.12)`）+ 轻微手贴倾角（−3° ~ +3°）。

主色板：
- **主文字 / 徽章钴蓝**：`#2E35C8`（核心视觉主色，覆盖 80% 以上的文字、序号圆底、对勾、问号圆点）
- **否定 / 警示印章红**：`#EF565D`（仅用于反面案例印章、否定标签）
- **便签/提示词卡片底**：纯白 `#FFFFFF`（截图/提问胶囊）或柔粉 `#F8CDD4`（长文/提示词卡）
- **全息彩虹渐变**：淡粉/浅黄/薄荷/天蓝/浅紫柔和过渡（仅用于 A 层级主标题、大号章节数字和结尾公式）

| 层级 | 用途 | 推荐字体（ChatCut 可渲染） | 颜色与贴纸样式 | 字号（占画幅高） |
| --- | --- | --- | --- | --- |
| A · 全息闪粉主标 / 章节大号 | 开篇核心主题、`01/02/03` 章节引入、高潮大词（如 `10x`、`input`） | 英文：Fredoka / Nunito Black / Poppins ExtraBold；中文：Noto Sans SC Black / 站酷酷圆 | 内部彩虹渐变 + `#2E35C8` 粗蓝描边 + 珠光闪粉模切白底 | 7–13% |
| B · 概念词 / 清单主条 | 关键词、右侧清单条、方法论要点 | Noto Sans SC Bold / Nunito Bold | 钴蓝 `#2E35C8` 实心字 + 珠光白边贴纸 | 3.2–4.5% |
| C · 手写标注 / 副标 / 疑问 | 补充解释（如 `not by training`、`with AI`、`too much info?`）、图示标注 | 英文：Caveat / Kalam；中文：Zhi Mang Xing / Long Cang | 钴蓝 `#2E35C8` 斜体手写 + 白色贴纸轮廓，可斜 2–5° | 2.6–3.6% |
| D · 左上章节常驻胶囊 | 全章持续提示当前进度（如 `01 reference`） | 数字白字粗体 + 标题钴蓝粗体 | `#2E35C8` 深蓝胶囊数字 + 连体白底珠光边标题胶囊 | 2.6–3.2% |
| E · 证据 / 截图 / 便签卡 | 真实网页/推文/产品截图、真实长文本或提示词展示 | 卡片内保留原图清晰度；配图标签用 B/C 层级 | 圆角 18–24px + 10–14px 珠光白边框 + 柔和投影，微斜 ±2–4° | 占右侧 40–55% 宽 |
| F · 符号与互动徽章 | Emoji 贴纸、蓝色对勾 `✓`、红色双框印章（`OUTDATED`）、禁行标、人物背后弧线 | 矢量 SVG / 粗体大写无衬线（印章） | 统一加同款模切白边与投影；印章用 `#EF565D` 双线圆角框斜 −4° | 3–6% |

> **克制原则**：同一画面同时保留的贴纸组不超过 1 组主主题（例如：左偏人物 + 右侧 3–5 条递进清单，或居中人物 + 顶部 1 主标 + 左右各 1–2 个短词）。讲完当前论点后，旧贴纸整组 6–8 帧轻淡出，避免桌面堆满杂物。

## 5. 字幕策略

- **默认不放底部全量滚动字幕**：本风格用高频、精炼的关键词贴纸直接把口播结构可视化，底部留给人物白边与干净方格纸，呼吸感极强。
- **静音刷屏平台可选方案**（若用户要求抖音/小红书必须带字幕）：
  - 底部单行极简小字（字号 2.4–2.8%，每行 ≤ 12 字），字体用 Noto Sans SC Medium，颜色用深钴蓝 `#2E35C8` 或深蓝灰 `#2B2D42` 配纯白细描边，不加黑底框、不加金黄弹跳，避免与贴纸系统打架。

## 6. 节奏与剪辑

- **语速与语音清理**：保持 **1.0×**（语速偏慢可微调至 1.05×）。在粗剪阶段把口误、重录、超过 0.35 秒的无效停顿剪干净（对标片实测几乎无 >0.5s 的死气停顿，仅在章节切换处留 0.4–0.5s 呼吸）。
- **三层视觉节奏**：
  1. **微节拍（每 1.5–3.5 秒）**：新贴纸随关键词起音帧弹出、清单逐条追加、Emoji 或印章盖章、旧贴纸成组淡出。
  2. **中节拍（每 10–25 秒）**：人物在“居中 ↔ 左偏”平滑滑动，切入右侧清单板或参考截图卡。
  3. **大节拍（每章节 / 每 25–45 秒）**：切换方格纸底色 + 大号彩虹章节编号亮相（`01`/`02`/`03`/`04`）→ 收缩或切换为左上角常驻胶囊。
- **开头前 3 秒**：第 0 帧即呈现“白边抠像人物 + 暖米方格纸”，1–1.5 秒内弹出第一组主题贴纸（概念词 + 手写副标），3 秒内建立鲜明的“贴纸手账”风格锚点。
- **结尾**：切到全息彩虹柔焦幕，顶部出终极等式贴纸（如 `taste =`），左右分列两个核心词，胸前出 `+` 徽章，说完最后一句留 0.5–1 秒收尾。

## 7. 转场与动效

| 事件 | 动效 / 转场 | 参数 |
| --- | --- | --- |
| 贴纸入场（词 / 胶囊 / 清单条） | 轻弹性缩放 Pop-in | `scale 0.82 → 1.04 → 1.0`，6–8 帧，ease-out |
| 贴纸退场 | 整组轻淡出 | opacity `1 → 0`，6–8 帧 |
| 印章 / 否定标入场 | 盖章压入（Stamp） | `scale 1.25 → 1.0` + 轻旋转定格，5–7 帧 |
| 背后弧形连线 | 路径描边生长（Stroke Draw） | 10–14 帧从左向右穿过人物头后 |
| 人物居中 ↔ 左偏 | 平滑水平缓动 | 12–18 帧，`cubic-bezier(0.22, 1, 0.36, 1)` |
| 章节方格纸换底 | 柔和色彩交叉淡化 | 8–12 帧 |

> 禁用：扫光、闪白、Whip Pan、剧烈震动、花字逐字弹跳。

## 8. 声音

- **口播人声**：优先降噪与均衡动态，保持清晰亲切的面对面质感；响度目标 **−15 ~ −13 LUFS**，动态范围平稳（对标片实测 −14.2 LUFS、LRA 1.8、真峰值 −3.2 dBTP），总线 Limiter ceiling 设为 `−1.5 dB`。
- **背景音乐**：**默认不加 BGM**，让观众专注内容本身与干净的贴纸节拍。若用户明确要底乐，只用极轻的纯乐器 Lo-fi / 轻节拍极简电子，人声设 `anchor`、音乐设 `follower`（`duckDepthDb -20` 以下）。
- **音效（极度克制，切忌过度）**：
  - **不要给每个小贴纸都配音效**（会非常吵）。
  - 仅在关键节拍点配轻盈柔和的音效：章节大号弹出（轻 pop / bubble）、高潮钴蓝幕切换（柔和 whoosh）、清单开篇第一条（轻纸张/点击）、红色印章盖下（短促低轻咚声）、结尾彩虹公式（极轻清脆 ding）。
  - 全片控制在 **8–15 个轻音效**，感知音量比口播低 12–16 dB。

## 9. 封面与片尾

- **封面**：暖米或全息彩虹方格纸 + 居中粗白边人物 + 头顶超大彩虹闪粉主题词（2–5 个短词或中文 4–8 字）+ 一侧手写副标。直接取开场主标题定格帧或专门做一张 1 帧封面 MG。
- **片尾**：无需厚重黑屏片尾卡；停在终极彩虹渐变幕的“公式化金句”画面 0.5–1 秒自然收尾即可。

## 10. ChatCut 组件清单（可复用）

优先在 ChatCut 里用 `chatcut-create-motion-graphics` 与 `chatcut-create-pixel-processor` 做成少量参数化组件复用：

| 组件 | 类型 | 核心可编辑属性 |
| --- | --- | --- |
| 方格纸背景板 | Motion Graphic（底轨） | `bgColor`（预设暖米/浅紫/粉灰/钴蓝/彩虹渐变）、`gridSize`、`gridOpacity`、`grainAmount` |
| 稳定白边抠像 | 原生 Portrait Mask + 自定义 Pixel Effect | `outlineWidthPx`（默认 22）、`outlineColor`（`#FFFFFF`）、`alphaSmoothRadius`、`shadowOpacity` |
| 全息主标题 / 大章节号 | Motion Graphic | `text`、`mode`（title / chapterNumber）、`fontSize`、`glitterAmount`、`rotationDeg` |
| 概念 / 手写贴纸 | Motion Graphic | `text`、`style`（boldSans / italicScript / stampRed）、`emoji`、`holographicBorder`、`rotationDeg` |
| 左上章节常驻胶囊 | Motion Graphic | `number`（`01`..）、`label`、持续整章 |
| 贴纸清单板 / 提问胶囊 | Motion Graphic | `headerEmoji`、`headerText`、`items[]`、`revealFrames[]`、`iconType`（number / question / check） |
| 倾斜证据截图卡 | Motion Graphic | `mediaAsset`、`captionBadge`、`cardTint`（white / pinkNote `#F8CDD4`）、`rotationDeg` |
| 背后弧形连线 | Motion Graphic（放人物轨下） | `leftLabel`、`rightLabel`、`curveOffsetY`、`drawDurationFrames` |

> 制作顺序：先验证“人像抠像 + 粗白描边”在 3 秒连续运动画面里**完全不闪烁**，再搭 1 个方格纸底 + 1 个概念贴纸看合成效果，通过后批量铺全片。

## 11. QA 验收

贴纸抠像风全程单机位抠像、靠 5–15% 画面面积的贴纸微节拍驱动变化，用默认 `--scene 0.06` 会漏检小贴纸，必须使用 `--profile sticker`：

```bash
python3 <skill-dir>/scripts/retention_qa.py 成片.mp4 --profile sticker --out qa_report
```

目标（`--profile sticker` 默认使用贴纸适配阈值 `--scene 0.018 --fade-scene 0.016`，`--static 5.0`）：
- **平均视觉变化间隔**：≤ 3.5 秒（对标片实测：1.42 秒，41.9 次/分钟）
- **最长静态段**：≤ 9 秒（对标片实测：5.6 秒）
- **静态占比（> 5 秒段）**：≤ 25%（对标片实测：7%）
- **前 3 秒视觉变化**：≥ 1 次（对标片实测：2 次）
