# 四轮 ChatCut 提示词生成规范

适用于用户只给文稿，或需要一套可复制的剪辑指令。先输出短拆稿，再输出四段完整的 `text` 代码块。每块包含本轮的具体台词、动作和验收，单独复制就能用。模板里的方括号是编写标记，交付时换成实际内容或移除不适用的条目。提醒用户确认前一轮结果后再发下一轮。

## 从文稿生成

1. **拆稿**：列出 Hook 原句、各章触发原句与胶囊标题、重点句的上层文字／下层高亮、CTA 原句。无 CTA 写“自然收尾”。上下层一起读时应保留原意。强调数据时保留单位、范围和“约”“最高”“仅针对”等限定词，分层也要能同时读到。
2. **定位**：没有成片时间轴时用精确原句作锚。重复短句用前后一句、章节上下文或第几次出现来消歧。即使逐字稿带源时间，也要在粗剪后重新定位；有已经核实的成片时间时才填时间码。文稿与转写不一致时，请 ChatCut 对照实际口播核验并报告找不到的锚点。
3. **填满四轮**：第一轮写出真实 Hook 与要保护的语义停顿；第二轮列出具体花字、动效、颜色及起点；第三轮逐章填真实标题、触发原句、A/B/C、补镜内容与检索词；第四轮把同一组实际花字、章卡和补镜事件映射到具体音效。提示词须能独立复制，核心清单不依赖外部拆稿表。
4. **按内容取舍**：没有适合的素材时可留在口播原景；真实界面操作用匹配的录屏，数据用对应图示或文字。在存在适合的话术时才加 CTA 包装。在同一拍有多种视觉事件时指定一个主音效。

## 第 0 轮 · 节奏蓝图（交付给用户确认，不发给 ChatCut）

先按 SKILL 第 0 轮输出蓝图表：一句话卖点、2–3 个 Hook 原句候选、目标时长、章节与版式、每 2–4 秒的视觉节拍表、重点词、视觉证据、结尾方式。下面四段指令都从这张表填充。

## 第 1 轮 · 粗剪定轨与节奏提速

```text
请在当前 ChatCut 项目里对口播做第 1 轮粗剪。设为 9:16（1080×1920），主讲人居中，可见高度以画面 60%–70% 为起点，保留自然头顶空间。
用「[Hook 原句及必要上下文]」作为前 3–5 秒的开场。需要时对照实际语速确认。后面保留以下内容锚点：[各章触发原句和要保留的重点或收尾原句]。
用转写去掉无意义语气词、失败起句和重复录制。收紧超过 0.30 秒且明显拖节奏的无声停顿，保护 [本稿的真实转折、停顿或数据读完后的节拍]。先试听 1.15×–1.20× 的自然度；有底噪或电平不齐时适度降噪、均衡音量。
请复核开头、一次接缝、换章和结尾，并给我最终粗剪时长、倍速、各章和重点词在成片轴上的锚点。锁定口播时序后暂停，等我确认再做第 2 轮。
```

## 第 2 轮 · 常规字幕与双层动态花字

```text
在第 1 轮确认的时间轴上做第 2 轮字幕。底部用白字黑边或半透明暗底的单行主字幕，中文每行约 12 字以内，按语义分行，保留数值与单位的连续阅读。
请逐条处理以下真实花字锚点：[原句或已核实成片时间 → 上层语境 / 下层重点 / 色值 / 入场方式]。上层用白色无衬线字，下层约放大 1.5 倍，金黄 #FFD700 为主，亮青 #00F5D4 少量使用。短标签用打字机，信息用上滑，核心数据可用发光聚焦。下层在重点词的实际起点出现，主字幕与花字尽量避免整句重复。
给第三轮的顶部章卡、人物及画中画留位。请展示一处重点词起点、最长一条字幕和一次动效预览，等我确认再做第 3 轮。
```

## 第 3 轮 · 章节卡与 B-roll 画中画轮替

```text
请在锁定时间轴上做第 3 轮。每到一章的触发台词，在顶部安全区放圆角常驻胶囊标题，保留到下章。请按下面的实稿清单放置：[触发原句 → 实际章卡短标题 / 本章 A、B 或 C / 补镜内容与检索关键词 / 补镜插入原句]。
A 用全幅相关补镜和发光圆形人像窗，可在背景与人物间加景深大字。B 用右下细白描边人像和左侧磨砂卡，按口播逐条显示 [本稿 B 章要点]。C 用底部圆角边框人像与上方 [本稿 C 章数字、单位或实际重点]。只实施清单中实际用到的版式，相邻章节依次轮换。
口播主画面按节拍表加推拉镜头：[原句 → 跳推 1.15× / 快推 1.25× / 缓推 1.1×]，句首开始，推近与拉回交替，不让头顶或下巴出画。说到具体部位或对象时用示意图：[原句 → 示意图内容]。
约每 2–4 秒检查一次视觉变化，任何超过 6 秒没有构图变化的段落都补一个节拍；演示和数据读完再切。补镜和重复人物层默认静音。预览每种已用版式和一次换章，复核字、脸和演示区的遮挡情况，等我确认再做第 4 轮。
```

## 第 4 轮 · 音效卡点与 BGM

```text
在第 3 轮确认的画面上做第 4 轮音效和混音。请按这份具体事件清单对齐音头：[本稿的打字机短词或标题 → 轻键击；实际卡片或花字上滑 → 轻 whoosh / pop；具体发光关键词 → pling / sparkle；具体换章或补镜切点 → 轻空气声]。以实际时间轴上的动画入点或切点为准，同一拍优先保留一个音效。
优先复用合适的现有底乐，否则选择与内容情绪相符的纯音乐。口播轨设为闪避锚轨、底乐设为跟随轨，底乐基础增益保持自然，靠自动闪避让出人声。试听首尾、接缝和两个典型卡点，完成后导出 1080p 预览，用留存 QA 检查平均视觉间隔 ≤3.5 秒、最长静态段 ≤6 秒、前 3 秒 ≥2 次变化、响度 −16 至 −13 LUFS，给出可编辑时间轴及验收结果。[用户有导出要求时填入具体规格。]
```

## 可移植执行规则

以下 YAML 可作为长期复用的规则文本，字段按使用界面映射。视觉预设见 [设计风格与版式](design-style.md)。

```yaml
workflow:
  stages: [rough_cut, typography, chapters_pip_b_roll, sfx_audio]
  confirm_each_round: true
  lock_speech_timing_in: rough_cut
pacing:
  review_silence_over_seconds: 0.30
  trial_playback_rate: [1.15, 1.20]
  review_visual_beats_seconds: [2, 4]
  max_static_seconds: 6
  hook_visual_changes_in_3s: 2
  punch_in_scale: [1.12, 1.30]
layout_rotation: [glowing_circle_pip, corner_cutout_frosted_list, bottom_frame_upper_metrics]
sound_map:
  typewriter: mechanical_key_click
  slide_up_or_frosted_card: soft_whoosh_or_pop
  emphasized_keyword: pling_or_shimmer
  b_roll_or_chapter_cut: light_air_whoosh
  bgm_ducking: {speech: anchor, music: follower}
qa:
  script: scripts/retention_qa.py
  avg_visual_gap_seconds_max: 3.5
  loudness_lufs: [-16, -13]
```

## 主题：暗调文案风（附加指令）

选了暗调文案风时，把下面这段加在每一轮指令前面；规则细节见 [theme-dark-copywriter.md](theme-dark-copywriter.md)。

```text
本条用「暗调文案风」：黑底暗光、低饱和、电影感。口播保持 1.0× 不提速，句间停顿留 0.35–0.6 秒，[金句原句] 说完后留 1.2–2.5 秒黑场或定格让音乐接上。
字幕放画面上三分之一、暖白单行一屏一句；金句用宋体卡（Noto Serif SC Black，暖白或暗金 #C9A063）或手写体（Zhi Mang Xing，橙 #E2733A），关键词只点红 #C8161D，一屏只用一种强调色，金句出现时隐藏同句字幕。
画面靠构图轮换制造变化：暗调中景 ↔ 圆形聚光 ↔ 黑场字卡 ↔ 纪实补镜，3–4.5 秒一换，不用跳推和弹跳动效。章节用黑场字卡（壹、贰、叁 + 宋体标题）和 Dip to Black 12–18 帧。
音乐用低频钢琴或氛围，说话时深度闪避、停顿处抬起；音效全片不超过 6 个。封面：一行 2–4 字红色毛笔大字 + 小号副标题 + 「第 N 集」。片尾：黑底圆形头像 + 欢迎关注 + 手写账号名。
```
