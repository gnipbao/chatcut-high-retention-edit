# 主题：暗调文案风（Dark Copywriter）

适合观点型、文案型、个人 IP 型口播：讲商业认知、创业、个人成长、“一句话戳人”的内容。气质是**低调、克制、有电影感**：大面积黑、少量红金点睛、字比画面更会说话。

> 风格来源：对一组“高级个体户 / 文案营销”类口播（参考目录 `舒老师风格/`，4 条，共约 11 分钟）逐帧拆解后归纳的通用规则。只提炼节奏、版式、字体和声音的规律，不复制原作的文案、标识、人物形象或账号名。

和默认的“高网感明快风”相比，本主题**慢一点、暗一点、字更有分量**：

| 维度 | 明快风（默认） | 暗调文案风 |
| --- | --- | --- |
| 语速 | 1.10–1.20× 提速 | 1.0×，保留停顿，约 3.8–4.2 字/秒 |
| 画面变化 | 2–4 秒一次 | 3–4.5 秒一次，允许 8–12 秒长镜头 |
| 推拉镜头 | 跳推、快推为主 | 几乎不用；最多 1.05–1.08× 缓推 |
| 素材要求 | 任意 | 最好暗光侧光拍；亮背景素材用人像遮罩换黑底（见第 2 节） |
| 花字 | 金黄双层、带弹跳 | 宋体陈述卡 + 手写金句，淡入或直切 |
| 转场 | 扫光、闪白 | 硬切、黑场、圆形聚光收拢 |
| 音效 | 每个动画都配 | 几乎不用，只在黑场字卡给一声低频 |
| 音乐 | 全程垫底 | 说话时压很低，停顿时抬起来“接话” |
| QA | `--profile bright` | `--profile cinematic` |

---

## 1. 画幅与构图

- **画幅**：参考片多为 720×1024（约 7:10），介于 3:4 和 9:16 之间。推荐两种输出：
  - 抖音 / 视频号：1080×1920，人物和字都放在中间 1080×1536 的“内框”里，上下留黑，像电影黑边。
  - 小红书：1080×1440（3:4）。
- **人物偏一侧，留大块黑色负空间**：人物占画面 40–60%，脸常在暗处一半；字幕和金句写在负空间里，不压脸。
- **四种基础镜头**，按节拍轮换：
  1. 暗调中景：人物在黑背景前，侧光，主体偏左或偏右。
  2. 圆形聚光：只留一个柔边圆里的人物（约画面宽 45–55%），其余全黑，上方放一句金句。
  3. 整屏黑场字卡：纯黑底，只有一两行字，1.5–3 秒。
  4. 纪实补镜：真实工作、活动、街景照片或视频，全屏，低饱和或黑白 / 棕褐。
- 手机主页、产品截图用**倾斜 3D 卡片**放在黑底上（约 8–12° 透视），而不是平铺全屏。

## 2. 调色（ChatCut Color 字段）

对口播主轨每个片段写入，先在一段上试色再批量：

```json
{"color": {
  "exposure": -0.3, "contrast": 1.2, "highlights": -0.25, "shadows": -0.35,
  "saturation": 0.78, "temperature": 5800, "fade": 0.03,
  "filmEffectsEnabled": true,
  "vignetteEnabled": true, "vignetteAmount": 0.55, "vignetteSize": 0.45, "vignetteSoftness": 0.7,
  "grainEnabled": true, "grainAmount": 0.15, "grainSize": 1.2, "grainImageDefocus": 1
}}
```

- 目标：黑位压实但不死黑，肤色保持暖、背景偏冷灰，整体饱和度低，只有字是彩色。
- 回忆、过去、团队故事段：`saturation` 0–0.15，`splitEnabled: true, splitHue: 35, splitAmount: 0.25`，做成棕褐怀旧色。
- **先看素材是不是暗光拍的。** 上面的参数是给“暗背景、侧光”素材的。实测在亮背景（米白墙、暖光落地灯）的口播上，即使把参数推到 `exposure −1.1, contrast 1.35, highlights −0.6, shadows −0.5, vignetteAmount 1.0, vignetteSize 0.32`，背景也只能压到中灰，做不出黑底。
- **亮背景素材的做法（实测有效）**：给口播片段加人像遮罩，背景直接变成纯黑，再叠上面的调色：

  ```json
  {"type": "pixel-effect", "assetId": "builtin:effect-mask", "targetItemId": "<口播片段>",
   "mask": {"mode": "set", "corrections": [], "nodes": [{
     "id": "<从 inspect_asset builtin:effect-mask 的 portrait 模板复制>", "kind": "portrait",
     "enabled": true, "invert": false, "startFrame": 0, "durationFrames": <片段帧数>,
     "parameters": {"feather": 10, "matteOffset": 2}, "operation": "intersect"}]}}
  ```

  注意：浅色饰品（白发箍、浅色帽子）和推镜放大时，抠像容易吃掉边缘，逐段看定格帧；吃边时把 `matteOffset` 调到 3–6，仍不行就改用椭圆遮罩做“圆形聚光”（`kind: "ellipse"`，`radius_x/y` 0.55–0.7，`feather` 60–120）。
- 圆形聚光镜头直接用椭圆遮罩：圆心对准脸，半径约画面短边的 45–55%，大羽化，其余全黑。

## 3. 字体与配色

**一屏只用一种主强调色。** 字体用 `search_fonts` 能查到的可渲染字体：

| 层级 | 用途 | 字体 | 颜色 | 字号（占画面高） |
| --- | --- | --- | --- | --- |
| A 常规字幕 | 跟读口播，一屏一句 | Noto Sans SC Bold（或 Noto Serif SC SemiBold） | 暖白 `#F2EFE9` | 3.0–3.4% |
| B 陈述金句卡 | 观点、结论、章节句 | Noto Serif SC Black / 项目内宋体（如 Xiangcui Jixue Song） | 暖白 / 暗金 `#C9A063` | 5–7% |
| C 手写金句 | 情绪句、反转句、口语化结论 | Zhi Mang Xing / Liu Jian Mao Cao / Long Cang | 橙 `#E2733A` 或红 `#D9342B` | 5–8%，可斜 3–6° |
| D 大字标题 | 封面、开篇关键词（2–4 字） | Ma Shan Zheng（毛笔）/ Noto Serif SC Black | 正红 `#C8161D` | 18–30%，可竖排 |
| E 英文小标 | 金句卡上方的点缀 | Noto Serif / Cormorant 全大写，字距 0.35–0.5em | 红 `#C8161D` 或灰 `#8A8580` | 1.4–1.8% |
| F 章节编号 | 段落序号 | 手写体大写数字：壹、贰、叁… | 暖白 | 7–9% |

- 句中关键词“点染”：一句里只把 1–2 个词换成红或金（例：“以前的高级是**大而全**”），其余保持白色。
- 手写金句保留句号“。”，有手写收笔的感觉；宋体卡不加标点。
- 偶尔用繁体字做宋体金句卡，强化复古感；常规字幕保持简体，方便阅读。
- 不用描边粗黑字、不用彩色底板、不用弹跳动效。

## 4. 字幕与金句节奏

- **常规字幕放在画面上 1/3**（人物头顶上方或负空间里），不放底部；单行、按意群一屏一句，最长 12 字。
- 字幕出现方式：直切或 6–8 帧淡入；不做逐字跳动。
- 每 10–20 秒给一个“金句时刻”（B / C / D 层级之一），持续到这句说完再多留 0.5–1 秒。
- 金句时刻和常规字幕**不同时出现**：金句卡出来时，这句的常规字幕隐藏（`set_card_style` `opacity: 0`）。
- 章节开头：先 1.5–2.5 秒黑场字卡（F 编号 + B 标题），再切回人物。

## 5. 节奏与剪辑

- **不提速**：保持 1.0×，只删口误、重录和无意义口癖；句间停顿压到 0.35–0.6 秒，而不是 0.25 秒。
- **金句后留白**：重要句子说完后保留 1.2–2.5 秒“沉默”，画面定格或切黑场，让音乐接上来。
- 镜头 3–4.5 秒一换，靠**构图切换**（中景 ↔ 圆形聚光 ↔ 黑场字卡 ↔ 纪实补镜）制造变化，而不是靠推拉。
- 深度陈述、情绪句允许 8–12 秒长镜头，但同一机位连续不超过 12 秒。
- **开头**：第 0 帧就有标题字（D 或 B 层级）+ 暗光人物，第一句话在 1 秒内开始；不做冷开场跳推。
- **结尾**：最后一句金句 → 1 秒留白 → 片尾卡。

## 6. 转场

| 场合 | 转场 | 参数 |
| --- | --- | --- |
| 句与句、镜头之间 | 硬切 | — |
| 段落 / 章节 | `builtin:transition-dip-to-black` | 12–18 帧 |
| 进入回忆、纪实段 | `builtin:transition-rack-focus` | 15–20 帧，全片 ≤ 2 次 |
| 聚焦到一个人 / 一句话 | 圆形聚光收拢：`builtin:effect-mask` 圆形遮罩从全画面缩到 50% | 12–20 帧 |
| 黑场字卡进出 | 字卡淡入淡出 | 6–10 帧 |

不用扫光、闪白、Whip Pan、Impact Shake。

## 7. 声音

- **口播**：降噪后保持原声质感，不加混响；人声为主，响度目标 −14 LUFS。
- **配音（无真人口播或补旁白时）**：低沉、偏慢、带一点气声的男声 / 中性声；语速 0.9–0.95×；句间停顿 0.6–1.0 秒。用 ChatCut 语音工具生成前先试一句。
- **音乐**：低频钢琴、大提琴、氛围或慢速 Lo-fi，无人声歌词。口播轨设 `anchor`，音乐轨设 `follower`，`duckDepthDb` 约 −18 到 −22（比明快风压得更深）；停顿处音乐自然抬起，参考片停顿处音乐约 −14 dB。
- **音效**：几乎不用。只在两处给声：黑场字卡入场（低频 boom / 胶片咔嗒，一声）、章节编号出现（纸张或打字机单击）。全片不超过 6 个。
- **响度**：−14 ~ −13 LUFS，真峰值 ≤ −1 dBTP。参考片普遍 −11 LUFS 且峰值削波，不要照抄。

## 8. 封面

- 画面：暗调人物（侧光、半脸在暗处）或纯黑底；人物占 40–60%。
- 标题：**一行 2–4 字的超大红色毛笔字或粗宋**（D 层级），可竖排压在人物一侧；下方一行小号暖白副标题（A/B 层级，≤ 12 字）。
- 系列感：左上或顶部小字“第 N 集”，所有集位置、字号一致。
- 除标题外整体低饱和；不加贴纸、箭头、表情包。
- 做法：在时间线第 0 帧放封面 MG（1–2 帧即可），导出后用 `ffmpeg -ss 0 -frames:v 1` 截出 1080×1440 和 1080×1920 两张。

## 9. 片尾卡

纯黑底 → 圆形暗角里的人物头像（约画面宽 35%）→ 下方一行宋体“欢迎关注”+ 一行红色手写体账号名（用引号包住）。停留 1.5–2 秒，音乐淡出。

## 10. MG 组件清单（用 `create-motion-graphics` 生成，可复用）

| 组件 | 可编辑属性 |
| --- | --- |
| 宋体金句卡 | 主句、英文小标、强调词、强调色、对齐、透明 / 黑底 |
| 手写金句 | 文本、字体（三选一）、颜色、倾斜角、位置 |
| 章节黑场卡 | 编号（壹贰叁）、标题、持续帧 |
| 圆形聚光遮罩 | 圆心、半径、羽化、收拢时长 |
| 倾斜手机卡 | 截图、倾斜角、阴影 |
| 封面 | 大字标题、副标题、集数、竖排开关 |
| 片尾卡 | 头像、账号名、引导语 |

先做“宋体金句卡”一个，放进真实画面检查字号、负空间和对比度，再批量出其他组件。

## 11. QA

```bash
python3 scripts/retention_qa.py 成片.mp4 --profile cinematic --exempt <黑场字卡和长镜头区间>
```

目标：平均画面变化 ≤ 4.5 秒、最长静态段 ≤ 12 秒、超过 6 秒的静态段占比 ≤ 40%、前 3 秒至少 1 次变化（或第 0 帧即有标题字）、响度 −16 ~ −13 LUFS、真峰值 ≤ −1 dBTP。参考片实测：平均 2.95–4.37 秒、最长 9.4–11.8 秒、静态占比 23–49%。

人工复核：随机抽 6 帧，检查每帧是否“只有一个视觉焦点、只有一种强调色、字不压脸”。
