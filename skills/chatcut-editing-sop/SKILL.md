# ChatCut 高网感口播剪辑 SOP（v2）

口播是听觉主轴，画面每一次变化都要帮观众“继续看下去”或“看懂正在说的东西”。v2 在原四轮包装之上补了两件事：**开剪前先画节奏蓝图**，**交付前用数据验收留存节奏**。

```
0 节奏蓝图 → 1 粗剪锁轴 → 2 字幕与花字 → 3 视觉节奏层 → 4 音效混音 → 5 留存 QA 与交付
```

## 必读与分工

- ChatCut Desktop：先读其自带的 `talking-head-guide`（语音剪辑原则、MG/B-roll/音乐/字幕细则），本 Skill 只补“网感与留存”层，不重复它的规则；冲突时以工具实时契约为准。MG 走 `create-motion-graphics`，转场/蒙版/特效走 `pixel-processing-gen`，字幕走 `transcription`。
- 具体工具用法读 [ChatCut 执行与验收](references/chatcut-execution.md)；节奏与 Hook 读 [留存节奏手册](references/retention-playbook.md)；视觉规范读 [设计风格与版式](references/design-style.md)；美妆/医美/健康类读 [垂类规则](references/niche-beauty-health.md)；只出指令时读 [四轮提示词规范](references/prompts.md)；一个完整跑通的样例见 [实测案例](references/case-brow-glabella.md)。

## 选择主题

开剪前先定主题，主题决定字体、配色、语速、转场、音乐和 QA 标准；下面各轮的默认值都是“明快风”，选了其他主题时，以主题文件为准覆盖。

| 主题 | 适合 | 关键词 | 文件 |
| --- | --- | --- | --- |
| 明快风（默认） | 知识科普、美妆、教程、种草 | 提速、跳推、金黄双层花字、音效卡点 | 本文件 + [设计风格](references/design-style.md) |
| 暗调文案风 | 观点、商业认知、创业、个人 IP、文案金句 | 黑底暗光、宋体 + 手写体、红金点睛、慢节奏留白、黑场字卡 | [theme-dark-copywriter.md](references/theme-dark-copywriter.md) |

用户说“舒老师那种”“暗调”“文案风”“高级感、电影感、黑底大字”“观点类口播”，或素材本身是暗光人像，就用暗调文案风。没说时按内容判断，拿不准就给两个主题各一张示意帧让用户选。

## 判断交付方式

- **出指令**：用户只给文稿/逐字稿，或要剪辑方案、提示词 → 先做第 0 轮蓝图，再按 [提示词规范](references/prompts.md) 输出可复制的分轮指令。
- **做剪辑**：有可唯一确定的项目或待剪原片，且用户要执行 → 按本 SOP 分轮完成。参考成片只当风格参考。
- **改旧版**：项目里已有成片时间轴时，用 `manage_timelines duplicate` 另起新版本时间轴（命名如 `v2 高留存`），旧版保留做 A/B 对比，不在原时间轴上覆盖。
- 默认 9:16（1080×1920）、30fps，保留用户已选规格。

## 运行规则

- 默认每轮结束交付本轮检查结果，等“继续”再进下一轮。用户明确要求一口气做完（含“测试一下效果”）时连续执行，但仍分轮提交、分轮验收，每轮自己看预览帧。
- 每轮记录：项目与时间轴 ID、本轮改动、预览证据、下一轮要用的锚点帧。
- 第 2 轮以后只在锁定时序上加包装。必须改口播剪点/速度时回第 1 轮重锁，并复核受影响的字幕、画面、音效。
- 对用户说明剪辑时引用实际台词，不说内部段号或 ID。

## 第 0 轮 · 节奏蓝图（不动时间轴）

读转写全文（`read_script`）和 9–16 张源画面（`inspect_asset sourceFrameCount`），产出一张蓝图表再开剪：

| 字段 | 内容 |
| --- | --- |
| 一句话卖点 | 这条视频让观众得到什么（结果 / 避坑 / 反常识） |
| Hook 候选 ×2–3 | 全片最强原句：冲突、结果前置、反常识、提问。标注原句和源时间 |
| 目标时长 | 默认素材净内容的 55–70%；60–90 秒是竖屏知识口播的常用区间 |
| 章节 | 2–4 个真实论点，每章：触发原句、≤4 字胶囊标题、版式 A/B/C/D |
| 节拍表 | 每 2–4 秒一个“视觉节拍”：用哪种手段（见下），对应哪句台词 |
| 重点词 | 每 8–12 秒最多一个双层花字；数字、部位名、结论优先 |
| 视觉证据 | 说到部位/对象/前后变化时，给出示意图、标注或补镜方案 |
| 结尾 | CTA 原句或“回环结尾”句（尾句能接回开头问题） |

视觉节拍手段按成本从低到高：推拉镜头（Instant 跳推 / Quick In / Slow Push）→ 双层花字 → 构图切换（中景↔近景↔画中画）→ 示意图 MG / 标注 → B-roll / 整屏卡片 → 抠像破框 / 文字在人物后。**同一手段不要连续用三次。**

蓝图过关：Hook 在原话里真实存在；每章都有至少一个“非推拉”的视觉证据；节拍表最长空档 ≤6 秒。

## 第 1 轮 · 语音粗剪与锁轴

- 按 `talking-head-guide` 做清理：`clean_script` 去固定口癖并把停顿压到约 0.25 秒；再用 `read_script → 编辑 timeline.md → apply_script` 做语义判断：选最佳重录、删失败起句、删“如果说啊”这类无信息起句。
- **冷开场**：把蓝图里最强的 Hook 句复制到最前（新增一行原句，不是移动），3 秒内说完；Hook 后紧接“为什么/怎么办”的承接句。开头不留“大家好/今天我们来聊”。
- **压缩到目标时长**：先删重复论证和离题，再删铺垫，最后才收紧语气。整句为单位取舍。
- **倍速**：短段试 1.10×–1.20×，开启保音调；听清数字、部位名、专业词再统一。语速本来就快时不提速。
- **过关**：试听开头、一处接缝、换章处、尾句；无吞字、缺主语、意外空隙或黑帧。记录帧率、口播末帧、各片段源区间与倍速、Hook/章节/重点词/CTA 的成片帧位。此后口播时序视为锁定。

## 第 2 轮 · 字幕与双层花字

- 原生字幕：底部单行白字 + 黑描边或半透明暗底，中文每行 ≤12 字，按语义断句，数字与单位不拆行。字幕顶边放在画面约 72–78% 高度，躲开平台底部 UI（约底部 15%）。
- 双层花字：上层白字交代语境（如“眉骨不够高”），下层关键词放大约 1.5 倍、金黄 `#FFD700`（少量薄荷 `#00F5D4`），在关键词**真实起音帧**入场。花字出现时，该句底部字幕保留但不重复整句。
- 入场动画按内容选：短标签 → 打字光标；信息条 → 上滑；结论/数字 → 模糊发光或撞字；否定或纠错 → 抖动/划掉。记录每个花字的入场帧和动画类型，第 4 轮直接按它配音效。
- 给第 3 轮留位：顶部章卡区、脸部、画中画区、示意图区。
- **过关**：预览开场、最长字幕、每个花字入场前后一帧；检查口型与字、数字单位、字形缺字、遮脸和同屏阅读负担。

## 第 3 轮 · 视觉节奏层

按蓝图节拍表落实，执行细节见 [执行与验收](references/chatcut-execution.md)：

1. **推拉镜头（打底）**：在句首/语义转折处对口播片段加 zoom 效果。跳切处用 `Instant` 1.12–1.20× 交替“近/远”；强调句用 `Quick In` 1.2–1.3×；长解释段用 `Slow Push` 1.08–1.15× 持续缓推。焦点对准脸（`focalPointY` 约 0.30–0.38）。放大后头顶、下巴不得出画，字幕区不得被脸挤占。
2. **章节卡**：每章触发帧放顶部胶囊章卡，可编辑标题，持续到下一章；换章配 6–12 帧的扫光/闪白转场。
3. **版式轮换**：A 发光圆形画中画、B 角落描边人像 + 磨砂信息卡、C 底部框景 + 上方数据、D 抠像破框 / 文字在人物后（见 [设计风格](references/design-style.md)）。相邻章节不用同一版式；章节少就少用。
4. **视觉证据**：说到具体部位、对象、步骤、前后对比时，用示意图 MG（线稿面部 + 高亮区域 + 标签）或可用补镜，持续到这句话说完。复用的口播画中画继承源区间与倍速，**必须用无音轨副本**，否则会多出一套重叠字幕（见执行文档）。
5. **巡检**：从头到尾按 2–4 秒节拍检查，任何 >6 秒无构图变化的段落都要补一个节拍（优先推拉或花字，其次示意图）。前 3 秒至少 2 次视觉变化（如首帧大字 + 跳推）。
6. **过关**：`read_captions` 确认字幕轨只有一条；预览每种已用版式、每次换章前后、每个示意图的定格帧；检查抠像边缘、人物大小、遮挡、可读性，对照第 1 轮锚点确认包装落在正确语音时刻。

## 第 4 轮 · 音效与混音

- 音效按第 2、3 轮记录的动画入点放，映射表见 [留存节奏手册](references/retention-playbook.md#动画音效对照)。同一拍只留一个主音效，密集处只给最重要的那个。音效轨不参与闪避。
- 背景音乐：纯音乐、无明显人声，情绪贴合（美妆/生活类偏轻快温暖）。口播轨设 `anchor`、音乐轨设 `follower` 自动闪避，音乐基础增益保持自然，不再额外压 −22 dB。时长裁到内容末帧，淡入淡出 1–2 秒。
- 剪辑接缝用 `smooth_audio` 或微淡化，确认短音效起音仍清楚。
- **过关**：试听首尾、接缝、两处花字卡点、一段连续口播；设备可用时按手机外放复听。

## 第 5 轮 · 留存 QA 与交付

1. 导出 1080p 预览（`export`，`track_progress target=export wait`）。
2. 运行 `python3 scripts/retention_qa.py <导出文件> --out <目录> --exempt 23.0-28.7,54.6-61.1`（路径相对本 Skill 目录；`--exempt` 填示意图/演示定格段的秒数区间；暗调文案风加 `--profile cinematic`，标准见主题文件），明快风对照目标：

| 指标 | 目标 |
| --- | --- |
| 平均视觉变化间隔 | ≤3.5 秒 |
| 最长静态段 | ≤6 秒（演示、示意图定格除外） |
| 静态占比（>4 秒段） | ≤15% |
| 前 3 秒视觉变化 | ≥2 次 |
| 整体响度 | −16 至 −13 LUFS，真峰值 ≤ −1 dBTP |

3. 有 WARN 就回第 3/4 轮补节拍或调电平，再导出复检。脚本只量化构图级变化（硬切、推拉跳变、整屏卡片），慢推和小花字不计入，所以 PASS 后仍要看联系表人工确认。
4. 交付：项目名与时间轴、成片路径、QA 前后对比、本次未能实现或需人工确认的部分（如未试听、抠像边缘）。用户需要剪映工程时用 `export format="jianying"`。
